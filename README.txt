منصة مسار التميز
1) افتحي المجلد في VS Code.
2) python -m venv .venv
3) .\.venv\Scripts\Activate.ps1
4) pip install -r requirements.txt
5) python app.py
6) افتحي http://127.0.0.1:5000
رمز الإدارة الافتراضي: منصة إبداعية
ملاحظة: كل مرحلة أساسية = 5 كتب، والريادة تعتمدها الإدارة بعد 25 كتابًا معتمدًا.


تحديث النسخة 3:
- إضافة مركز مصادر التعلم تحت اسم المدرسة.
- تغيير زر دخول الإدارة إلى مركز مصادر التعلم.
- استبدال النقاط بعملات: 10 عملات لكل كتاب معتمد.
